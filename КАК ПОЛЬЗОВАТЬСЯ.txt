шторКа — сайт на своём компьютере
==================================

РАБОТА ВДВОЁМ ЧЕРЕЗ GITHUB — см. файл «ПРАВИЛА_РАБОТЫ_ВДВОЁМ.md» рядом.

ДВА ЗАПУСКА
- «Запустить сайт.bat» — онлайн-сайт со ссылкой для клиента и Сани.
  Если папка подключена к GitHub, показывает ОБЩУЮ версию (папка _online) и сам подтягивает
  свежие правки каждые 30 секунд. В окне будет видно, кто и что обновил.
- «Проверить мои правки.bat» — твоя рабочая папка, только на этом компьютере, без ссылки.
  Для проверки перед отправкой в GitHub. Можно держать открытыми оба.

ЗАПУСК ОНЛАЙН-САЙТА
1. Двойной клик по «Запустить сайт.bat».
2. Через 10–20 секунд в окне появится ссылка вида https://что-то.trycloudflare.com
   Она уже скопирована — просто вставьте её в чат клиенту и Сане.
   Ещё она сохраняется в файл «ссылка.txt» рядом.
3. Сайт откроется у вас в браузере.

ОСТАНОВКА
- Нажмите Enter в чёрном окне.
- Если окно закрыли крестиком — двойной клик по «Остановить сайт.bat».

ВАЖНО
- Ссылка работает, пока включён компьютер и открыто окно запуска.
- При каждом запуске ссылка НОВАЯ — после перезапуска отправьте её заново.
- Первый запуск скачивает программу cloudflared (около 60 МБ, один раз) в папку tools.
- Папку _online руками не править: она каждый раз перезаписывается версией с GitHub.

ЕСЛИ ЧТО-ТО НЕ ТАК
- Windows пишет «Защитник Windows предотвратил запуск» → «Подробнее» → «Выполнить в любом случае».
- Нет ссылки, а сайт открылся только локально → проверьте интернет; если не помогло — включите zapret и запустите снова.
  Подробности ошибки — в tools\tunnel.log.
- В окне «Git не найден» → установите Git for Windows (git-scm.com/download/win) и перезапустите.
- В окне «нет связи с GitHub» → сайт работает на последней скачанной версии; проверьте интернет / zapret.
