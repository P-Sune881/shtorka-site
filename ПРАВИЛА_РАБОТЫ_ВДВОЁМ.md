# шторКа — как работаем вдвоём через GitHub

Общая версия сайта лежит в приватном репозитории на GitHub. У каждого своя рабочая копия на своём компе.
Онлайн-сайт (ссылка trycloudflare) крутится на одном компе и сам подтягивает с GitHub свежую версию каждые 30 секунд.

## Кто какие файлы правит

| Зона | Хозяин | Файлы |
|---|---|---|
| Дизайн и цвет | Саня | `site/styles.css`, `site/index.html`, картинки в `site/assets/` (кроме velvet и room.hdr), `site/policy.html`, `site/consent.html` |
| Шторы и анимация штор | второй участник | `site/curtains.js`, `site/assets/velvet/`, `site/assets/room.hdr`, `site/vendor/`, `tools/`, `.bat` |
| Общий файл | по договорённости | `site/app.js` — перед правкой написать второму в чат |

Цвета штор и карниза (`color`, `sheen`, `metal` в начале `curtains.js`) подбирает дизайнер,
а вписывает их хозяин штор: присылай числа в чат.

Если очень надо поправить чужой файл — сначала напиши. Правки в разных файлах никогда не конфликтуют.

## Каждый раз

1. **Перед началом работы:** GitHub Desktop → **Fetch origin** → если появилось **Pull origin**, нажми его.
2. **Работаешь** в своей рабочей папке (никогда не в `_online`!).
3. **Проверяешь у себя:** двойной клик по **«Проверить мои правки.bat»** → правишь → F5.
4. **Отправляешь:** GitHub Desktop → внизу слева коротко, что сделал (например, «Шторы: мягче возврат ткани»)
   → **Commit to main** → **Push origin**.
5. Через полминуты правки на онлайн-сайте — обнови страницу (F5).

Отправляй часто и маленькими порциями (раз в час-два), а не раз в день: так конфликтов почти не бывает.

## Если что-то пошло не так

- **Push не проходит, пишет про новые изменения** → нажми **Pull origin**, потом снова **Push origin**.
- **GitHub Desktop пишет «conflict»** — вы оба поменяли одни и те же строки. Он покажет файл: открой его,
  оставь нужный вариант (или оба), удали строки `<<<<<<<`, `=======`, `>>>>>>>`, сохрани → Commit → Push.
  Не уверен — скинь файл Claude в чат, он разберёт.
- **Сломал что-то и хочешь назад** → GitHub Desktop → вкладка **History** → правой кнопкой по нужной правке → **Revert**.

## Для Claude в чате (вставить в начало нового чата)

> Работаем над сайтом «шторКа» вдвоём через GitHub. Моя рабочая папка — `<путь к папке шторКа-сайт>`.
> Запроси к ней доступ и прочитай `ПРАВИЛА_РАБОТЫ_ВДВОЁМ.md` в корне. Я отвечаю за зону: `<дизайн и цвет / шторы>`.
> Правь только файлы моей зоны; общий `app.js` — только если я скажу. Папку `_online` не трогай.
> Git-команды не выполняй: Pull, Commit и Push я делаю сам в GitHub Desktop.
> Файлы клади прямо в папку, без архивов.

## Один раз: настройка

**Тот, у кого сайт онлайн (папка уже есть):**
1. Установить **GitHub Desktop** (desktop.github.com) и **Git for Windows** (git-scm.com/download/win), войти в GitHub.
2. GitHub Desktop → **File → Add local repository** → выбрать папку `шторКа-сайт` →
   «This directory does not appear to be a Git repository» → **create a repository** →
   галочку README не ставить, Git ignore: **None**, License: **None** → **Create repository**.
3. **Publish repository** → галочка **Keep this code private** оставить → **Publish**.
4. На github.com в репозитории: **Settings → Collaborators → Add people** → аккаунт Сани.
5. Запустить **«Запустить сайт.bat»**. Первый раз он скачает общую версию в `_online`
   (может попросить войти в GitHub в браузере — один раз).

**Саня:**
1. Установить **GitHub Desktop**, войти, принять приглашение (придёт на почту или в уведомления GitHub).
2. GitHub Desktop → **File → Clone repository** → `шторКа-сайт` → выбрать, куда положить → **Clone**.
3. Работать в этой папке, проверять через **«Проверить мои правки.bat»**.
